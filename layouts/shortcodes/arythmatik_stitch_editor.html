    Pattern

    Click a step to switch it on or off. Steps 1, 5, 9 and 13 are the beats. Changed steps are marked until you press Send.

    On the module:

    Generate makes a new pattern, Mutate changes a few steps of the pattern shown here (unsent changes are sent first). Both play at once; press Send to save the result on the module.

    Presets

    The grooves from the module's AUTO banks, each with the fill the module plays with it. Load into grid only changes the grid: press Send to put it on the module.

    Pattern code: –

    Settings

    Each change goes to the module at once, and the module saves it by itself. The names in brackets are the items on the module's display.

    Sequencer

    Fill every (F-EV) – Set on the module, AUTO only

    In AUTO mode the module plays each pattern for REP × 16 steps and picks a new preset after SW of these blocks; with fills on it plays a fill every F-EV repeats. F-EV has no USB command, so the editor only shows it.

    Module

    The IN item in the module's bottom menu changes the RST action live; RIN is the action it starts with. Display 180° is for a module mounted upside down: CLK/RST and the outputs are swapped to match.
